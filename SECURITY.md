# Границы безопасности

Управление GM1 проходит через сопряжённый HomeKit, свежий UART pre-read, единственную запись и проверочное чтение. Временный ручной допуск удалён по решению владельца. При отказе ожидающие команды удаляются; повторная попытка требует нового действия пользователя. UART контроллера не предоставляет аутентификации и атомарной операции «изменить поле», поэтому гонка со штатным пультом остаётся ограничением.

Обычный образ не включает WebLog. Диагностический образ открывает `/tion-status` по HTTP без HAP-аутентификации и раскрывает сетевые/аппаратные идентификаторы встроенной страницы HomeSpan. Используйте его только в доверенной локальной сети, без проброса порта в интернет. Монитор сохраняет разрешённые поля в CSV `0600`; этот CSV всё равно относится к частным данным эксплуатации.

Setup AP включается автоматически при отсутствии Wi-Fi-настроек, ограничен пятью минутами и использует известный пароль HomeSpan `homespan`. Настраивайте стик при физическом доступе в доверенной обстановке; отдельный личный восьмизначный код задаётся в форме Setup AP для каждого стика. Случайный bootstrap verifier нужен для исключения общего default-кода, его код не публикуется и не предназначен для ручного pairing. Физический доступ к нешифрованной Flash позволяет прочитать NVS; проект не заявляет защиту от такого доступа.

В `rc2` аудит выявил ошибки пересекающихся команд, повторного отказа и обработки NVS. Они исправлены; текущий кандидат `0.2.0-gm1-diag` установлен на обоих стиках с сохранением NVS и сопряжения. Базовый старт и обычные команды подтверждены, суточные прогоны продолжаются; редкие аппаратные отказы ещё не испытаны. [Отчёт аудита](docs/audit-2026-09-24.md) содержит детали и ограничения.

## Сообщение об уязвимости

GitHub Private Vulnerability Reporting включён. Для приватного сообщения используйте [Report a vulnerability](https://github.com/viventu/tion-homekit/security/advisories/new) в **Security → Advisories** репозитория `viventu/tion-homekit`. Не создавайте публичный issue с деталями уязвимости.

Укажите затронутую версию, возможные последствия и минимальный синтетический способ воспроизведения. Не присылайте Wi-Fi-пароли, коды сопряжения, NVS, дампы Flash, реальные адреса или серийные номера. Передачу частных данных согласовывают отдельно. Проект пока не устанавливает срок реакции и не обещает поддержку экспериментальных образов; после GM поддерживаемые версии будут перечислены здесь.
