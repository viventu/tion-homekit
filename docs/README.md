# Документация

Начните с [обзора проекта](../README.md): там перечислены возможности, требования и команды сборки. Проект находится в стадии предварительного релиза; проверенная конфигурация — Tion Family 4S с контроллером `02D0` и ESP32-S3 с 16 МБ Flash.

- [Оборудование и подключение](hardware.md) — совместимость, порт бризера и подготовка стика.
- [Установка и восстановление](setup.md) — резервная копия, прошивка, настройка Wi-Fi и HomeKit, обновление.
- [Диагностика](diagnostics.md) — локальная страница состояния, сбор журнала и разбор типовых проблем.
- [Поддержка](../SUPPORT.md) и [безопасность](../SECURITY.md) — куда сообщать об ошибках и уязвимостях.
