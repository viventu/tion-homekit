# Документация

Начните с [обзора проекта](../README.md): там перечислены возможности, требования и команды сборки. Проект находится в стадии предварительного релиза; проверенная конфигурация — Tion Family 4S с контроллерами `02D0` и `04C7` и ESP32-S3 с 16 МБ Flash.

- [Диагностика](diagnostics.md) — локальная страница состояния, сбор журнала и разбор типовых проблем.
