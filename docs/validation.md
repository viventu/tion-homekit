# Сводка проверок

Состояние на **26 сентября 2026 года**. Текущий кандидат — `0.2.0-gm1`; стабильный выпуск ещё не объявлен. Сводка отделяет проверки кода от аппаратных результатов конкретной версии.

**PASS** означает успех указанного сценария, **PARTIAL** — частичную проверку, **NOT RUN** — отсутствие испытания, **IN PROGRESS** — незавершённое наблюдение. Результат ранней версии не переносится автоматически на новую сборку.

## Аппаратные результаты

Испытания проводились на двух ESP32-S3 с 16 МБ Flash и двух Tion Family 4S `02D0`. Сырые журналы, адреса и резервные копии не публикуются.

| Область | Версия и результат | Предел |
| --- | --- | --- |
| ROM и резервные копии | PASS: чип/Flash идентифицированы, полные копии считаны и проверены | Полная обратная запись копии пока NOT RUN |
| Обновление и сопряжение | GM1, PASS на двух экземплярах: APP проверен, NVS до/после совпала, pairing сохранился | Только проверенная разметка разделов |
| Старт, UART и обычное управление | GM1, PASS: свежие состояния, питание/скорость, удаление старого переключателя допуска | Не является повтором всех функциональных испытаний |
| Питание, ступени 1–6, пульт | `rc1`, PASS на одном экземпляре | Полный набор на GM1 отдельно не повторён |
| Рециркуляция, звук, подсветка | `rc1`/`rc2`, PASS на двух экземплярах | Сохранение звука/подсветки после перезапуска контроллера NOT RUN |
| Пятиминутное ускорение | `rc1`/`rc2`, PASS: максимум и возврат; вмешательство пульта отменяло таймер | Граничные отказы GM1 на оборудовании NOT RUN |
| Нагрев и уставка | `rc1`, PARTIAL: разрешение нагрева, уставки 22–24 °C, ненулевой `heater_percent` | Длительная терморегуляция и независимый замер NOT RUN |
| Температуры и фильтр | `rc1`, PARTIAL: показания около комнатной температуры и предупреждение фильтра совпали с UART | Отрицательные значения и настоящий сброс ресурса NOT RUN |
| Отказ сброса фильтра при работающем бризере | `rc1`, PASS: команда отклонена без UART-записи | Не подтверждает настоящий сброс после замены |
| Длительное наблюдение GM1 | IN PROGRESS: отдельное окно 24 ч для каждого экземпляра | Результат появится в [отчёте GM1](gm1-validation.md) после завершения |

В раннем опыте чтения непрерывная работа устройства превысила 8 ч, максимальная пауза завершённых heartbeat TX составляла 3014 мс. Поминутный журнал покрывал только часть этого окна. Это наблюдение не заменяет полный суточный журнал GM1 и не измеряет запас питания.

## Открытые проверки

- Маркировка/ревизия платы, PSRAM, электрические уровни и запас питания — NOT RUN.
- Полное восстановление Flash и кнопочный Command Mode HomeSpan — NOT RUN.
- Независимая проверка базы HAP, отображение `StatusFault` и отрицательных температур в Apple «Дом» — NOT RUN.
- Длительный нагрев, независимое измерение температуры выхода и настоящий сброс после замены фильтра — NOT RUN.
- Предельные задержки при Wi-Fi/provisioning, восстановление после потери UART-ответа и исчерпания watchdog-бюджета на оборудовании — NOT RUN; соответствующая логика проверена на host.
- Побайтовая воспроизводимость сборок между ОС/каталогами и полный состав лицензий итогового бинарника — не подтверждены.
