# Публикация исходников

Инструкция для сопровождающего [viventu/tion-homekit](https://github.com/viventu/tion-homekit). Репозиторий уже публичный; изменения проходят через pull request и обязательный CI. Выпуск версии описан [отдельно](releasing.md).

## Обычное изменение

Создайте ветку от публичной `main`, подготовьте изменение по [CONTRIBUTING.md](../CONTRIBUTING.md) и откройте PR. Перед слиянием проверьте состав diff и статусы `host (g++)`, `host (clang++)`, `firmware`. Защита `main`, запрет force push и обязательные проверки сохраняются.

Используйте адрес GitHub `noreply`, если личная почта не должна попадать в публичные коммиты. Точный адрес доступен в настройках аккаунта; настройка **Keep my email addresses private** также относится к операциям через веб-интерфейс. Проверьте автора до публикации.

## Перенос из локальной истории с частными данными

Если исходный checkout содержит частные данные в истории, переносите **только проверенное дерево файлов**. Не отправляйте его ветки/теги, не добавляйте частный репозиторий как remote публичного checkout и не переносите `.git`.

Из чистого закоммиченного исходника выполните:

```sh
python3 scripts/prepare-public-snapshot.py --output /tmp/tion-homekit-source-snapshot
```

Каталог результата должен быть новым и находиться вне исходного репозитория. Скрипт экспортирует только tracked-файлы проверенного commit, сохраняя режимы файлов. Каталоги `.private/`, `.arduino/`, `.build/`, бинарные дампы и типовые секреты отклоняются проверкой.

Просмотрите снимок и проверьте его сканером секретов. В отдельном checkout публичного репозитория создайте ветку от `origin/main` и перенесите только нужные файлы из снимка. Проверьте `git diff`, новые и удалённые файлы; затем создайте обычный публичный коммит и PR. Совпадение дерева можно сверить через `git rev-parse HEAD^{tree}`; частные commit ID не нужны в публичной документации.

Этот процесс не требует заново создавать репозиторий или переписывать существующую публичную историю.

## Что проверять при публикации

- В составе файлов, коммитов, тегов и логов нет паролей, NVS, полных Flash-образов, адресов домашней сети и сырых диагностических данных.
- Документация описывает текущую версию и отделяет подтверждённые результаты от незавершённых испытаний.
- Лицензия собственного кода и сторонние notices сохранены.
- Доступны [приватные сообщения об уязвимостях](https://github.com/viventu/tion-homekit/security/advisories/new); включены secret scanning и push protection.
- Проверены шаблоны issue/PR, ссылки и результаты GitHub Actions.

Игнорирование файлов в Git и автоматический сканер не заменяют просмотр diff. Бинарные артефакты проходят [отдельную проверку](binary-compliance.md).
