# Оборудование и подключение

Проект рассчитан на **один стик для одного Tion Family 4S**. Для сборки используется конфигурация базовой LilyGO T-Dongle-S3: ESP32-S3, 16 МБ Flash, без PSRAM. Версии Plus и Dual не считаются взаимозаменяемыми.

| Компонент | Проверенная конфигурация | Ограничение |
| --- | --- | --- |
| Бризер | Tion Family 4S, контроллер `02D0` | Другие модели и версии аппаратно не проверены; `03CD` блокируется кодом |
| Микроконтроллер | ESP32-S3, 16 МБ Flash | Точная ревизия платы и наличие PSRAM требуют проверки для каждого экземпляра |
| Интерфейс | UART 9600 бод, TX GPIO20, RX GPIO19 | Совместное использование этих линий с USB не допускается |
| Настройка | BOOT/GPIO0, статусный APA102 GPIO39/40 | Кнопочный Command Mode HomeSpan на целевой плате ещё не испытан |

Версии источников и основания выбора выводов перечислены в [реестре](evidence.md). Двусторонний UART и базовое управление проверены на двух экземплярах `02D0`, но электрические уровни и запас питания прибором не измерены. Эти результаты не подтверждают совместимость произвольной платы или разъёма.

## Перед первой прошивкой

1. Сверьте модель и маркировку платы с [документацией LilyGO](https://github.com/Xinyuan-LilyGO/T-Dongle-S3/blob/bb7654607d280fc2a1451d24abf6ed027287d416/docs/en/t-dongle-s3/REAMDE.MD). Подтвердите чип и Flash через ROM; не выбирайте параметры Plus/Dual по внешнему сходству.
2. Снимите стик с бризера и подключите к компьютеру с удержанием BOOT. Используйте один источник питания.
3. Сохраните полную резервную копию, её SHA-256 и соответствие конкретному стику. Копии содержат NVS и не должны попадать в репозиторий.
4. Сверьте таблицу разделов с новой сборкой и убедитесь, что повторный вход в ROM работает. Подробные команды — в [инструкции установки](setup.md).

Не меняйте eFuse, Secure Boot, Flash Encryption или прошивку контроллера Tion. При несовпадении чипа, разметки, объёма памяти, необычном нагреве или нестабильном обнаружении остановите установку.

## Перед подключением к бризеру

Форма интеграционного разъёма не означает, что к нему можно подключить обычный USB-кабель компьютера. Сверьте распиновку конкретного порта и платы, ориентацию, напряжение питания, логические уровни и допустимый ток. Не соединяйте работающий порт Tion с компьютером или USB-UART без проверенной схемы; не подавайте питание одновременно с двух сторон.

Для новой аппаратной конфигурации сначала проверяют восстановление снятого стика, затем чтение состояния без управляющих записей. Образ `firmware/TionReadOnly` предназначен для такого исследования; `spike/` используется только для проверки компиляции и не предназначен для установки.

## Контроль обмена

UART обслуживает периодический heartbeat с целевым интервалом 3 с. Диагностика измеряет паузу между завершениями передачи; рабочий критерий испытаний — менее 5 с. Предупреждение upstream об отключении питания порта примерно через 8–10 с без обмена не является измерением для каждого контроллера.

При потере питания, повторных перезапусках, неожиданном изменении режима или нагреве прекратите команды, снимите стик и восстановите штатную работу бризера. Не устраивайте циклические перезапуски и перебор кадров на устройстве.

Порядок функциональных испытаний — в [плане](one-visit-test.md), результаты — в [сводке](validation.md). Обновление выполняется через USB на снятом стике; OTA отключена.
