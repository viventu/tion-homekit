# Кандидат GM1 — 2026-09-26

Владелец разрешил подготовить GM, обновить оба стика и собирать логи **24 часа**. Временный переключатель «Разрешить управление» удаляется; повседневное управление через сопряжённый HomeKit доступно без ручного допуска. Образ `0.2.0-gm1-diag` остаётся **кандидатом GM**, пока установка и суточный прогон не завершены. Это разрешение на локальное обновление устройств, не публикация бинарников.

## Изменения и совместимость

- Состояние поддерживаемого устройства проверяется перед каждой командой. Нет 30-минутного таймера или rearm после ошибки; автоматических повторных записей по таймауту нет.
- Ограничения нагрева, режима работы, свежести, порядка UART-ответов и сброса фильтра сохранены. Ошибка удаляет ожидающую команду и отменяет возврат действующего ускорения; новое действие пользователя может запустить новую команду.
- Удалены только сервис допуска и его характеристики, IID 13–15. `homeSpan.resetIID(16)` сохраняет прежние IID всех остальных плиток и не назначает им старые идентификаторы допуска. Host-тест сверяет номера всех сервисов и характеристик. Владелец подтвердил на обоих бризерах исчезновение переключателя и работу питания/скорости без повторного сопряжения; независимая полная HAP validation остаётся NOT RUN.
- В диагностике и CSV появились версия образа и `Control available`. Старый `Control armed` по-прежнему читается монитором для совместимости с журналами `rc2`.

Обновляем по одному: A, затем B. Каждый стик снять с Tion, подключить к Mac с BOOT при единственном источнике питания, сверить MAC с его резервной копией и проверить ROM/Flash/security. Перед записью сохранить текущий APP для отката, NVS и таблицу разделов в отдельные приватные файлы. Записать **только APP по `0x10000`**, отдельно выполнить `verify-flash`, считать NVS повторно и сравнить побайтно до первого обычного запуска. Загрузчик, разметку, eFuse, настройки HomeKit и контроллер Tion не менять. Откат — сохранённый прежний APP этого стика через ROM BOOT с сохранением текущей NVS.

После возвращения в тот же Tion проверить `0.2.0-gm1-diag`, свежие состояния, отсутствие ошибок и сохранённое сопряжение. Владелец проверяет исчезновение переключателя допуска, остальные плитки и обычные команды. Физического сброса фильтра без замены и намеренного нарушения протокола на реальном Tion не проводить.

## Суточное наблюдение

Для каждого стика отдельный новый CSV с правами `0600`, интервал 60 с, длительность 24 ч. Старые журналы сохраняются отдельно; оба прежних монитора `rc2` остановлены перед обновлением соответствующих стиков. A собирается с 2026-09-26 10:07:43 UTC, B — с 10:22:11 UTC после проверенного запуска в своём Tion. Ожидаемое завершение — 2026-09-27 соответственно в 13:07:43 и 13:22:11 МСК; фоновая проверка назначена на 13:30 МСК. Mac должен оставаться включённым и доступным в той же сети; `caffeinate` предотвращает автоматический сон при бездействии. Монитор только читает HTTP-диагностику и не посылает управляющих команд.

```sh
python3 scripts/review-soak.py .private/soak/GM1-A.csv .private/soak/GM1-B.csv \
  --expected-hours 24 --interval 60 --expected-version 0.2.0-gm1-diag
```

Имена в примере заменяются фактическими файлами из приватного манифеста. До установки нового образа отсчёт не начинается. Итог требует полного окна, правильной версии, отсутствия reset, stale UART, ошибок и потери связи, достаточной памяти/стека и heartbeat gap меньше 5 с. Наблюдение при обычном использовании не заменяет ещё не проведённые электрические измерения, зимние тесты и проверку всех редких отказов. Результаты нового образа фиксируются отдельно; GM не объявляется прошедшим по факту сборки.
