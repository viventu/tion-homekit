## Установка и обновление

Укажите ссылку на инструкцию **для этого tag**, требования к исходной версии и необходимость миграции, если она есть. Объясните сохранение сопряжения и путь восстановления.

Если выпуск содержит только исходники, явно укажите это и дайте команды локальной сборки. Коды сопряжения и Wi-Fi каждый пользователь настраивает самостоятельно.

## Артефакты

Заполняется только для опубликованных файлов после [проверки бинарного состава](binary-compliance.md).

| Файл | Назначение / адрес Flash | Размер, байт | SHA-256 | Лицензии и notices |
| --- | --- | ---: | --- | --- |
|  |  |  |  |  |

Не прикладывайте NVS, полный Flash, `.merged.bin` или данные домашней сети. Хэш бинарника должен соответствовать испытанному файлу. Если диагностический образ входит в assets, укажите, что его HTTP-страница доступна без аутентификации HomeKit.
