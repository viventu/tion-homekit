# Правила общения

В обсуждениях проекта общайтесь уважительно и по существу. Не допускаются оскорбления, преследование, угрозы, публикация чужих частных данных и намеренное препятствование работе других участников. Критика кода и решений приветствуется, если она конкретна и направлена на улучшение проекта.

Владелец может скрыть или удалить нарушающие правила комментарии и закрыть обсуждение. Для жалобы на поведение используйте встроенную функцию GitHub **Report content**; для вопроса о правилах откройте issue без частных сведений. Уязвимости сообщайте по отдельному порядку из [SECURITY.md](SECURITY.md).
