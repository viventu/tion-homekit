# Tion 4S → HomeKit

[![Проверки](https://github.com/viventu/tion-homekit/actions/workflows/check.yml/badge.svg)](https://github.com/viventu/tion-homekit/actions/workflows/check.yml)

Управляйте бризером **Tion Family 4S** из приложения Apple «Дом». Стик на ESP32-S3 подключается к интеграционному порту бризера и добавляет его в HomeKit через Wi-Fi с помощью [HomeSpan](https://github.com/HomeSpan/HomeSpan).

Один стик обслуживает один бризер. Для работы не нужны Homebridge, MQTT или отдельный сервер.

Проект находится в стадии предварительного релиза. Это независимая DIY-прошивка, не официальный продукт Tion и не сертифицированный аксессуар Apple.

## Возможности

- Включение, выключение и выбор одной из шести скоростей.
- Управление нагревом приточного воздуха и заданной температурой.
- Показ температур воздуха на входе и выходе бризера.
- Переключение притока и рециркуляции.
- Ускорение вентиляции на пять минут.
- Управление звуковыми сигналами и подсветкой.
- Предупреждение о необходимости замены фильтра.

## Что понадобится

| Компонент | Требования |
| --- | --- |
| Бризер | Tion Family 4S с интеграционным портом; проверена прошивка контроллера `02D0` |
| Стик | LilyGO T-Dongle-S3, ESP32-S3, 16 МБ Flash, конфигурация без PSRAM |
| Сеть | Wi-Fi 2,4 ГГц |
| Apple Home | Приложение «Дом» и HomePod или Apple TV в роли домашнего центра |
| Компьютер | macOS или Linux для сборки и прошивки |

Совместимость с другими моделями Tion, версиями контроллера и вариантами платы не подтверждена. Перед установкой сверьте оборудование с [руководством по подключению](docs/hardware.md).

## Установка

### 1. Соберите прошивку

Понадобятся Git, Bash, Python 3.9+, `curl` и `tar`. На Apple Silicon также нужны Command Line Tools с `make`. Установка инструментов требует нескольких гигабайт свободного места.

Проект использует Arduino CLI **1.5.1**, Arduino-ESP32 **3.3.8** и HomeSpan **2.1.8**. Скрипт установит закреплённые версии в каталог `.arduino`:

```sh
git clone https://github.com/viventu/tion-homekit.git
cd tion-homekit

scripts/install-toolchain.sh
export ARDUINO_CLI="$PWD/.arduino/bin/arduino-cli"
export ARDUINO_CLI_CONFIG="$PWD/.arduino/arduino-cli.yaml"
export HOMESPAN_LIBRARY_DIR="$PWD/.arduino/libraries"
scripts/build-homekit.sh
```

Готовые файлы появятся в `.build/homekit/`. Сборка не записывает их на устройство. Установщик запускается один раз; для следующих сборок достаточно настроить три переменные окружения и выполнить `scripts/build-homekit.sh`.

### 2. Прошейте и настройте стик

Следуйте [инструкции по установке и восстановлению](docs/setup.md): сохраните резервную копию, проверьте разметку памяти и прошейте стик, снятый с бризера. Затем подключите его к домашнему Wi-Fi и задайте собственный код сопряжения HomeKit.

### 3. Добавьте бризер в «Дом»

В приложении «Дом» выберите **«Добавить аксессуар» → «Другие варианты»**, укажите код сопряжения и выберите комнату. Отключите стик от компьютера и установите в порт бризера. После подключения появятся элементы управления и показания датчиков.

Для каждого дополнительного бризера повторите настройку с отдельным стиком и кодом сопряжения.

## Особенности

Температура в карточке нагрева относится к воздуху на выходе бризера, а не к комнате. Ускорение реализовано самой прошивкой; особенности возврата скорости после сбоя связи описаны в [руководстве](docs/setup.md#известные-ограничения-интерфейса).

Обновление прошивки выполняется через USB. OTA пока не поддерживается. Сброс ресурса фильтра и отображение отрицательных температур в «Доме» остаются экспериментальными функциями.

## Разработка

Тесты на компьютере проверяют протокол, HomeKit и взаимодействие с симулятором бризера. Для них нужен Clang или GCC с санитайзерами; полная сборка использует окружение из инструкции выше.

```sh
scripts/test-host.sh --coverage
scripts/check.sh
```

CI проверяет GCC и Clang, санитайзеры, статический анализ и сборку всех вариантов прошивки. Для производственного C++ требуется 100% покрытия строк и ветвей.
