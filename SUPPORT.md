# Поддержка

Для вопросов по установке и воспроизводимых ошибок используйте GitHub Issues после открытия репозитория. Сначала проверьте [README](README.md), [установку и восстановление](docs/setup.md) и [известные ограничения](docs/spec.md). Укажите версию образа, модель стика, версию контроллера Tion и обезличенные шаги воспроизведения. Если устройство ведёт себя неожиданно, прекратите команды HomeKit и верните удобный режим штатным управлением; при необходимости снимите стик.

Не публикуйте пароли, коды сопряжения, NVS, полный Flash, полные MAC, домашние адреса и необработанную страницу `/tion-status`. Для уязвимостей следуйте [SECURITY.md](SECURITY.md), а не обычному issue. Коммерческая поддержка и гарантированное время ответа не предоставляются.
